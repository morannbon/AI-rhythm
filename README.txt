# AI-rhythm v1.0.6

## v1.0.6 の更新内容

- 録画・予約で実際に選んだ理由をより重視し、作品、人物、検索条件の違いを踏まえたおすすめを改善しました。
- 作品名・シリーズ・話数の自動整理と、蓄積した番組データを使った継続学習を改善しました。
- 録画品質の情報を保存し、品質異常があった番組の「取り直し候補」を長期保持できるようにしました。取り直し候補から録画予約を自動作成することはありません。
- 過去の取り直し候補を効率よく照合するため、保存データの読み込みと管理処理を改善しました。
- その他軽微な修正。

## 製品概要

AI-rhythmはTvAIrの番組表・予約・録画実績から好みを学習し、おすすめと新しい番組の発見を支援するプラグインです。主要機能はローカル情報だけで動作します。

## 動作環境

- Windows 10 / Windows 11
- .NET 8 Desktop Runtime
- 対応TvAIr：v1.2.12以上。v1.2.12の正式公開ソースと使用API・必要なHost契約を照合しています。実機動作確認環境はv1.2.13です。
- x64・x86のReleaseビルド構成を用意しています。実機での動作確認はx64環境です。
- ソースをビルドする場合はVisual Studio 2022と.NET 8 SDKが必要です。

## 主な機能

- 録画・予約履歴を利用したおすすめ番組の表示
- 普段の好みとは少し違う番組を提示する「発見」
- 作品、ジャンル、人物、放送局、時間帯などを組み合わせた継続的な学習
- 出演者・原作者・脚本家・監督など、番組に関わる人物情報を利用したおすすめ
- 同じ作品やシリーズをまとめる番組名の自動整理
- 話数やシリーズ情報を利用した続き物の判定
- 録画傾向の集計・表示
- 録画結果を利用した「取り直し候補」の表示
- 学習データのバックアップ・復元
- おすすめ・学習データ・全蓄積データのリセット

## 使うほど育つおすすめ

AI-rhythmは、「何を録画したか」だけを見るのではありません。

たとえば、普段なら選ばない作品でも、好きな出演者が出ているから見ることがあります。原作者が好きだからドラマを見る、脚本家や監督をきっかけに新しい作品を見る、といった選び方もあります。

AI-rhythmは、こうした番組を選ぶ理由につながる情報も学習材料として扱います。

主な学習材料は次のとおりです。

- 作品やシリーズ
- ジャンル
- 番組名に含まれる語句
- 出演者
- 原作者
- 脚本家
- 監督・演出
- 司会・ゲスト・解説などの出演情報
- 制作・音楽などの番組に関わる情報
- 放送局
- 放送される時間帯
- ユーザー自身が行った予約
- 人物を指定して探した操作
- 成功した録画の実績

これらを一つだけで判断するのではなく、複数の材料を組み合わせてユーザーごとの傾向を作っていきます。

そのため、単純に「ドラマをよく録画するからドラマだけを出す」といった推薦ではありません。

作品そのものを知らなくても、よく見る出演者や関心のある制作陣が関わっていることから候補になる場合があります。反対に、タイトルやジャンルが似ているだけで常に強くおすすめするわけでもありません。

利用を続ける中で新しい録画・予約・明示的な操作が増えると、学習内容も更新されていきます。

### 自動検索予約も学習材料です

自動検索やキーワード検索は、番組表から自分で見つけきれない番組を拾い、撮り逃しを防ぐための普段の操作です。AI-rhythmは、そこから得られた予約・録画・番組情報も、番組表からの直接予約と同じく正の事実として蓄積します。

1番組につき、タイトル、ジャンル、出演者・制作陣、放送局、時間帯など取得できた関連項目へそれぞれ1件分の事実を積みます。自動検索・キーワード検索で正の検索条件が実際にマッチした場合、その検索条件も別の1件分として積みます。同じ人物が番組情報にも検索条件にも現れた場合は、由来の異なる2つの事実として両方を保持します。

NOT / 除外条件は検索対象を狭めるための条件であり、好みのマイナス評価には使いません。加点もしません。プログラム予約は番組を選んだ意図を判定できないため、予約事実は保持しますが嗜好項目への加点は行いません。

同じ番組の予約と録画成功が別ストアに存在しても、同一予約IDに属する一連の出来事を二重加点しません。一方、第1話、第2話のように別々の番組として成立した録画は、それぞれ独立した事実として残します。これらの事実は時間経過で減点・消去せず、数年にわたる蓄積の中で、どの作品・人物・ジャンル・局・時間帯などが継続して増えるかを推薦時に利用します。

正規表現などのNOT・除外条件は、検索結果を絞るための条件です。NOTに指定された語句や対象を「嫌い」としてマイナス評価することはありません。

### おすすめを表示しただけでは学習しません

おすすめ画面に番組が表示されたことや、表示された番組を選ばなかったことだけを理由に、好み・嫌いを判断することはありません。

ユーザーの実際の検索・予約・録画など、普段の利用で生じた事実を学習材料にします。

## 番組名とシリーズの整理

テレビ番組のタイトルには、話数、シーズン、再放送表記、番組枠名、特集名など、さまざまな情報が付くことがあります。

AI-rhythmは、それらを単純に削除するのではなく、蓄積した番組情報を比較しながら、どこまでを同じ作品・シリーズとして扱うべきかを判断します。

十分な判断材料がない場合は無理に統合せず、番組情報が増えるまで判断を保留します。

特定の番組名だけを対象にした個別設定を増やすのではなく、蓄積された番組データ全体から共通する特徴を学習していきます。

## 「発見」について

AI-rhythmは、すでに好きだと分かっている作品だけを並べることを目的としていません。

これまでの録画・予約・人物への関心などから考えて、興味を持つ可能性はあるものの、普段の選択とは少し異なる番組も候補に加えます。

いつもの番組を見つけやすくしながら、自分では検索しなかった番組にも出会えることを目指しています。

## 外部情報について

AI-rhythmの主要機能は、TvAIr内に保存された番組表、録画実績、予約実績などのローカル情報だけで利用できます。

番組名や作品情報を確認するために追加情報が有効な場合は、TvAIrが管理する外部情報取得機能を補助的に利用することがあります。

現在利用する外部情報サービスはTVmazeです。

AI-rhythm自身が直接インターネットへ接続することはありません。

外部情報を利用するには、TvAIrの設定で次の条件を満たしている必要があります。

1. TvAIrの「ネットワーク利用」がON
2. AI-rhythmのインターネット利用が許可されている

どちらかが許可されていない場合、AI-rhythmは外部情報を利用しません。

外部情報を利用できない場合でも、録画実績、予約実績、番組表などのローカル情報を利用したおすすめ・発見・学習などの主要機能はそのまま利用できます。

録画ファイルそのものを外部サービスへ送信することはありません。

## 保存するデータ

AI-rhythmは、利用を続けることで学習に使う情報を蓄積します。

主に次の情報を保存します。

- 成功した録画の実績
- ユーザー自身が行った予約や明示的な操作から得た学習情報
- 作品・人物・ジャンルなどに関する学習情報
- 番組名やシリーズを整理するための学習情報
- おすすめや発見に利用する学習情報
- 外部情報から得た補助情報
- 利用回数などの集計情報

録画ファイルそのものをAI-rhythmが保存・管理することはありません。

現在の情報から再計算できるおすすめ順位などは、可能な限り固定した結果として保存せず、蓄積した情報を現在の判定方法で再評価します。

## バックアップと復元

AI-rhythmの設定画面から、蓄積したデータをバックアップできます。

長期間利用した学習データや録画実績を引き継ぎたい場合は、PCの再構築やTvAIrの再インストールを行う前にバックアップしてください。

保存したバックアップはAI-rhythmから復元できます。

## リセット

AI-rhythmには用途の異なる3種類のリセットがあります。

### おすすめリセット

おすすめに関するユーザー設定を初期状態へ戻します。

### 学習データリセット

学習した好みや判定情報をリセットします。

蓄積した録画実績は残します。

### 完全リセット

AI-rhythmが蓄積した学習情報や録画実績を含め、すべての保存データをリセットします。

## インストール

1. 配布ZIPを任意のフォルダへ展開します。
2. Visual Studio 2022で `AIrhythm.BasicPlugin.sln` を開きます。
3. ソリューション構成を `Release` にします。
4. 使用する環境に合わせて `x64` または `x86` を選択します。
5. ビルドして生成された `AIrhythm.BasicPlugin.dll` を確認します。
6. TvAIrを終了します。
7. `AIrhythm.BasicPlugin.dll` を `TvAIr\Plugins` フォルダへ配置します。
8. TvAIrを起動し、AI-rhythmを利用できることを確認します。

## 更新

旧バージョンから更新する場合は、TvAIrを終了してから新しい `AIrhythm.BasicPlugin.dll` へ置き換えてください。

長期間蓄積した学習データがある場合は、必要に応じて更新前にバックアップしてください。

## 過去版の更新履歴

## v1.0.5

- 録画・予約履歴を長期的に蓄積してユーザーごとの傾向を学習する仕組みを大幅に強化しました。作品、ジャンル、番組名に含まれる語句、出演者・原作者・脚本家・監督などの人物情報、放送局、時間帯など、複数の材料を組み合わせておすすめへ反映します。
- 番組表からの直接予約、自動検索予約、キーワード検索からの予約を、日常利用から得られる正の事実として加点型で蓄積します。自動検索だから弱める、という扱いはしません。
- 人物が番組情報に含まれていた事実と、その人物を検索条件として使った事実は別々に加点します。たとえば出演者「西野七瀬」が番組情報にあり、同時に「西野七瀬」で検索して予約した場合は、それぞれ独立した正の事実として蓄積します。
- 番組名、シリーズ、話数、シーズン、再放送表記などを整理する仕組みを大幅に改善し、同じ作品や続き物をより適切にまとめられるようにしました。
- 蓄積した番組情報から番組名の特徴やシリーズのまとまりを継続的に学習し、特定の番組ごとの個別ルールを増やさずに判定を改善していく仕組みを強化しました。
- 「見つける」画面のおすすめと発見候補へ学習結果をより広く反映し、普段の好みに近い番組と少し意外な番組を組み合わせて提示するようにしました。
- 録画履歴や予約状況を利用した続き物の判定を改善しました。
- 外部情報の利用方法を整理し、必要な場合だけTvAIr本体のネットワーク設定に従って補助情報を利用するようにしました。ネットワークを利用しない場合でも主要機能はそのまま利用できます。
- 外部の補助情報を確認する対象は、録画・予約などの利用実績に加えて、過去の問い合わせが実際に役立ったかも蓄積して選ぶようにしました。限られた問い合わせ回数を、より有効な番組確認へ回せるよう継続的に調整します。
- 学習データのバックアップ、復元、各種リセットを整理し、長期間蓄積したデータを管理しやすくしました。
- TvAIrのライト／ダークテーマ変更をAI-rhythm画面へすぐ反映できるようにしました。
- おすすめ計算や番組名整理などの処理を大幅に効率化し、番組数や学習データが多い環境でのメモリ使用量と処理負荷を改善しました。
- TvAIr側の番組・予約データが更新される瞬間と画面更新が重なった場合でも、一時的に番組が0件にならないよう、取得の再試行と直前の正常データを利用する保護を追加しました。
