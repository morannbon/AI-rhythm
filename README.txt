AI-rhythm v1.0.3

TvAIrの番組表、予約、録画実績をもとに、録画傾向に合う番組を見つけやすくするプラグインです。画面上部に現在のバージョンを表示します。

動作環境

- TvAIr 1.2.0
- Windows x64 / x86

インストール

Visual Studio 2022でAIrhythm.BasicPlugin.slnを開き、利用するTvAIrに合わせてRelease / x64またはRelease / x86でビルドしてください。生成されたAIrhythm.BasicPlugin.dllをTvAIrのPluginsフォルダーへ配置します。

主な機能

- 録画実績と予約内容からおすすめ番組を表示
- 録画総本数、ジャンル別内訳、タイトル上位10を表示
- よく録る放送局、時間帯、曜日の傾向を表示
- 現在録画中の番組を表示
- 録画失敗または録画品質に問題があった番組の再放送候補を「取り直しチャンス」として表示
- 今季の新番組から録画傾向に合う候補を表示
- 普段とは少し違う番組も発見候補として表示
- 気分、時間、目的から候補を探すリズム検索
- おすすめ番組をそのまま予約
- タイトル部の「更新」で長時間開いた画面を明示的に再取得
- 表示件数、優先する言葉、除外する言葉を設定
- AI-rhythm独自の学習情報をリセット可能
- TvAIrのライト／ダーク表示と、操作・選択・無効・注意操作などの状態表現に追従

おすすめスコア

スコアは、成功した録画実績、予約、シリーズ、タイトル傾向、放送局、時間帯、最近の選択などから算出します。ジャンル嗜好も成功した録画実績を基準にします。表示値は、その時点の候補全体に対する相対的な位置が分かるよう、平均50・標準偏差10を基準とする偏差表示へ変換します。

録画回数や自動検索予約のような強いシリーズ証拠は、同じ安定系列として正規化できた番組だけで共有します。題名の一部が似ているだけの関連番組へ、同一シリーズの強い証拠をそのまま貸しません。

有効な自動検索・キーワード由来の予約は、継続して録りたい意思表示として通常の単発予約より強めに扱います。無効な予約は正の嗜好材料に使わず、無効であることだけを「嫌い」とは判断しません。

おすすめの表示は、まず録画・予約・「気になる」などから理由を説明できる候補を優先し、その土台が十分にある場合だけ、既存の嗜好と接点を持つ発見候補を少量混ぜます。固定比率ではなく「納得が先、意外性が後」を優先し、件数合わせのために弱い候補を水増ししません。

ほとんど録画していないジャンルは、別の強い一致理由がない限り低いスコアになります。「いつもと違う発見」に表示する番組も、発見候補だからという理由だけでスコアを高くしません。

分析ダッシュボード

録画実績から、ジャンル、タイトル、放送局、時間帯、曜日の傾向を表示します。ジャンル別内訳はTvAIrのMediaInsightsが提供する録画履歴ジャンル集計を表示し、その他の録画実績集計とは用途を分けています。

画面幅に応じて配置が自動で切り替わり、チャートの補助文字と操作部品の状態色は本体テーマへ追従します。

取り直しチャンス

録画失敗または録画品質に問題があった録画と、番組表にある再放送候補を照合して表示します。取消・中止は対象に含めません。同じ番組である可能性が高い候補を優先します。

好みに刺さる新番組

新番組、初回、第1話、新シリーズなどの番組情報を手掛かりに候補を抽出し、録画傾向に合う順に表示します。特定ジャンルだけに固定せず、録画傾向が変われば候補も追従します。

リズム検索と「気になる」

番組名が決まっていなくても、気分、空き時間、目的を入力して候補を探せます。「気になる」の追加・解除はTvAIr Runtimeの正式なAction経路で保存します。

学習情報リセット

「学習情報リセット」は、AI-rhythm独自の次の情報をまとめて初期化します。

- 最近の探し方
- 「気になる」選択

TvAIr本体の録画履歴、予約、録画ファイル、AI-rhythmの通常設定は削除しません。そのため、リセット後も録画履歴から算出される録画傾向は利用されます。

予約

未予約の番組には「予約する」を表示します。予約済みの番組は重複して予約しません。

予約結果の表示にトースト通知や通知音は使用しません。

局の扱い

AI-rhythmは局の識別に NID / TSID / SID の組を使用します。局名は現在のTvAIrが返す表示名を使うため、局名変更だけで録画傾向・おすすめ・「気になる」の学習が別物に分断されません。
