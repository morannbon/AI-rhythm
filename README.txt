# AI-rhythm v1.0.9

## 最新の更新内容

- 自動検索で一つのルールから多数の予約が作られても同数の独立した好みとして数えないようにしました。手動予約と録画実績は区別して評価します。
- 学習開始直後の少数の予約だけで成熟度が急上昇しないよう改善しました。録画0件から1件に増えても以前の学習根拠が突然失効しない連続的な評価を採用しました。作品・ジャンル・人物・題名・予約・録画などの根拠を合わせて推薦と発見を評価します。ジャンルの均等割当は行いません。
- 作品名に付く特集案内・出演者紹介・字幕版・吹替版・制作情報を共通の解析で区別します。作品の正式名称や続編番号は維持します。
- 録画実績があるのにランキングの棒が表示されない問題を修正しました。総合とジャンル別のグラフで共通の表示色を使用します。
- 映画の続編や独立作品のPart番号を識別します。スポーツ大会のPart番号や放送日は大会名と分けて扱います。
- 予約の種類が不明な録画とプログラム予約を好みの学習に加点しないようにしました。録画結果の事実は取り直し候補の判定に利用します。
- 取り直し候補では同じ作品・シーズン・放送回と確認できる番組を表示します。正常な録画結果が確認できた候補は除外します。

## 製品概要

AI-rhythmはTvAIrの番組表・予約・録画実績から好みを学習するプラグインです。おすすめと新しい番組の発見を支援します。主要機能はPC内の情報だけで動作します。

## 動作環境

- Windows 10 / Windows 11
- .NET 8 Desktop Runtime
- 対応TvAIr：v1.2.15以上。TvAIr v1.3.0でも動作を確認しています。
- TvAIrと同じアーキテクチャのx64またはx86版を使用してください。実機確認はx64環境です。
- ソースからビルドする場合はVisual Studio 2022と.NET 8 SDKが必要です。

## 主な機能

- 録画・予約履歴を利用したおすすめ番組の表示
- 「今夜」は18:00～翌4:00です。「今日」は当日24:00までです。「これから」は今後6時間です。「寝る前」は夜の短い番組を探します。
- 普段の好みと少し異なる番組を提示する「発見」
- 作品・ジャンル・人物・放送局・時間帯を組み合わせた継続的な学習
- 出演者・原作者・脚本家・監督などの人物情報を使うおすすめ
- 番組名の自動整理と同じシリーズの話数判定
- 録画傾向の集計と表示
- 録画結果を利用した「取り直し候補」の表示
- 学習データのバックアップと復元
- おすすめ・学習データ・全蓄積データのリセット

## 使うほど育つおすすめ

AI-rhythmは録画したジャンルだけで好みを決めません。

普段は選ばない作品でも好きな出演者が出演していることがあります。原作者や脚本家をきっかけに新しい作品を選ぶ場合もあります。こうした情報も学習の材料として扱います。

主な学習材料は次のとおりです。

- 作品やシリーズ
- ジャンル
- 番組名に含まれる語句
- 出演者
- 原作者
- 脚本家
- 監督・演出
- 司会・ゲスト・解説などの出演情報
- 制作・音楽などの番組に関わる情報
- 放送局
- 放送される時間帯
- ユーザー自身が行った予約
- 人物を指定して探した操作
- 成功した録画の実績

これらの情報を組み合わせてユーザーごとの傾向を学習します。

よく見る出演者や関心のある制作陣が関わる作品は候補になる場合があります。タイトルやジャンルが似ているだけで強くおすすめするわけではありません。

新しい録画・予約・明示的な操作が増えると学習内容も更新されます。

### 自動検索予約も学習材料です

自動検索やキーワード検索は番組を見つけて撮り逃しを防ぐための操作です。そこから得られた予約・録画・番組情報を学習に利用します。

一つの自動検索ルールが多数の予約を作っても同数の独立した好みとは数えません。同じ検索意図から作られた予約は弱い根拠として評価します。直接選んだ予約や録画結果とは区別します。

録画は1番組ごとの事実として保存します。直接選んだ予約も独立した意思表示として扱います。出演者や作品名の根拠についても出所を区別します。

NOT / 除外条件は検索対象を絞るための設定です。好みの加点にも減点にも使いません。プログラム予約は好みの実績・集計・学習・おすすめから除外します。ただし録画結果の記録と取り直し判定には使用します。

同じ予約から生じた予約情報と録画成功は二重加点しません。第1話と第2話などの別々の録画はそれぞれ事実として保持します。蓄積した情報を時間経過だけで減点・削除せず長期的な傾向の評価に利用します。

### おすすめを表示しただけでは学習しません

おすすめに表示された作品を選ばなかったことだけで嫌いと判断しません。実際の検索・予約・録画などの操作を学習材料とします。

## 番組名とシリーズの整理

テレビ番組には話数・シーズン・再放送表記・番組枠名・特集名などが付く場合があります。

AI-rhythmは番組情報の蓄積と比較によって同じ作品やシリーズを判定します。判断材料が十分でない場合は無理に統合しません。

特定の番組名だけを対象にした個別ルールは増やさず番組データ全体に共通する特徴を学習します。

## 「発見」について

既に好みだと分かっている作品だけを並べることは目的としていません。これまでの録画・予約・人物への関心などを手掛かりに少し意外な番組も候補へ加えます。

普段検索しなかった作品と出会えることを目指しています。

## 外部情報について

**外部情報の利用は初期状態ではOFFです。** 利用する場合はTvAIrの設定で次の両方を許可してください。

1. TvAIrの「ネットワーク利用」をONにする
2. AI-rhythmのインターネット利用を許可する

両方の許可が有効な場合だけTvAIrが管理する外部情報取得機能を使用します。利用する外部情報サービスはTVmazeです。番組名や作品情報の照合に役立つ場合に補助情報を取得します。

AI-rhythm自身が直接インターネットへ接続することはありません。いずれかの許可がOFFの場合は外部情報を取得しません。PC内に保存された番組表・録画実績・予約実績によるおすすめ・発見・学習は引き続き利用できます。

取得済みの補助情報は保存される場合があります。録画ファイルそのものを外部サービスへ送信することはありません。

## 保存するデータ

AI-rhythmは利用を続けることで学習情報を蓄積します。主な保存対象は次のとおりです。

- 成功した録画の実績
- ユーザー自身が行った予約や明示的な操作から得た学習情報
- 作品・人物・ジャンルなどに関する学習情報
- 番組名やシリーズを整理するための学習情報
- おすすめや発見に利用する学習情報
- 外部情報から得た補助情報
- 利用回数などの集計情報

録画ファイルそのものをAI-rhythmが保存・管理することはありません。

現在の情報から再計算できるおすすめ順位は可能な限り固定した結果として保存しません。蓄積した情報を現在の判定方法で再評価します。

## バックアップと復元

AI-rhythmの設定画面から蓄積したデータをバックアップできます。PC再構築やTvAIr再インストールの前にはバックアップを作成してください。保存したバックアップはAI-rhythmから復元できます。

## リセット

AI-rhythmには用途の異なる3種類のリセットがあります。

### おすすめリセット

おすすめに関するユーザー設定を初期状態へ戻します。

### 学習データリセット

学習した好みや判定情報をリセットします。蓄積した録画実績は残します。

### 完全リセット

AI-rhythmが蓄積した学習情報や録画実績を含むすべての保存データをリセットします。

## インストール

### ビルド済みZIPから導入する場合

通常の利用ではVisual Studioによるビルドは不要です。

1. TvAIrを終了します。
2. TvAIrと同じアーキテクチャの `AI-rhythm_v1.0.9_x64.zip` または `AI-rhythm_v1.0.9_x86.zip` を取得して展開します。
3. ZIP内の `AIrhythm.BasicPlugin.dll` をTvAIrの `Plugins` フォルダへ配置します。更新時は既存DLLを上書きします。
4. TvAIrを起動してAI-rhythmを利用できることを確認します。

### ソースZIPからビルドする場合

1. ソースZIPを任意のフォルダへ展開します。
2. Visual Studio 2022で `AIrhythm.BasicPlugin.sln` を開きます。
3. ソリューション構成を `Release` にします。
4. TvAIrと同じ `x64` または `x86` を選択してビルドします。
5. TvAIrを終了します。
6. 生成された `AIrhythm.BasicPlugin.dll` をTvAIrの `Plugins` フォルダへ配置します。
7. TvAIrを起動してAI-rhythmを利用できることを確認します。

## 更新

TvAIrを終了してから新しい `AIrhythm.BasicPlugin.dll` に置き換えてください。学習データと録画実績を引き継ぐために保存済みのデータは削除しないでください。必要に応じて更新前にバックアップを作成してください。
