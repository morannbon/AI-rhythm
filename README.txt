# AI-rhythm v1.0.8

## v1.0.8 の更新内容

- 対応するTvAIrのバージョン表記を現在の機能に合わせて更新しました。
- 録画履歴が後から反映された場合でも確定した録画を累計本数に正しく加算します。同じ録画を繰り返し計上せず再起動・バックアップ復元後も集計を継続します。
- プログラム予約による録画は実績・録画品質・取り直し記録として保持しおすすめの好みや出演者の学習には使わないようにしました。
- 予約の種類を確認できない録画は勝手に好みとして評価しないようにしました。
- 画面のテーマ切替時にページ全体を読み直さず色を反映する処理を改善しました。
- おすすめの判定と画面のテーマ切り替えを共通の設定に基づく処理へ整理しました。
- 保存した録画実績の番組名や放送局が後から別番組の情報に置き換わらないよう改善しました。
- 同じ録画番号が別の放送で使われても過去の録画実績を上書きしないよう改善しました。保存済みの録画実績と取り直し記録を引き続き利用できます。
- 「今夜のおすすめ」を夜6時から翌朝4時までの番組に限定して午前・昼の番組が混ざらないよう改善しました。
- 番組検索では「今夜」「今日」「これから」「寝る前」の時間帯を区別できるようにしました。
- 同じシリーズの話数ごとに付く番組紹介文を放送情報との照合によって区別し作品をまとめる精度を改善しました。
- 出演者や制作スタッフの情報に複数の名前がつながっている場合誤った好みの学習に使わないよう改善しました。
- 番組宣伝と本編を区別して短い宣伝番組が通常のおすすめに混ざらないよう改善しました。
- 別番組の告知が番組名の後ろに付いている場合でも実際に放送する作品を優先して識別するよう改善しました。
- シーズン名を維持したまま明確な話数と各話タイトルを分けて扱うよう改善しました。
- 番組名を整理する学習とおすすめを選ぶ際の判定を改善しました。
- 録画・予約実績や学習情報の保存・読み込みを改善しました。
- 外部の番組情報が取得できない場合でもPC内の情報を使っておすすめを継続します。
- その他軽微な修正。

## 製品概要

AI-rhythmはTvAIrの番組表・予約・録画実績から好みを学習しおすすめと新しい番組の発見を支援するプラグインです。主要機能はローカル情報だけで動作します。

## 動作環境

- Windows 10 / Windows 11
- .NET 8 Desktop Runtime
- 対応TvAIr：v1.2.15以上。
- x64・x86のReleaseビルド構成を用意しています。実機での動作確認はx64環境です。
- ソースをビルドする場合はVisual Studio 2022と.NET 8 SDKが必要です。

## 主な機能

- 録画・予約履歴を利用したおすすめ番組の表示
- 「今夜」は18:00～翌4:00（深夜は当日の4:00まで）。「今日」は当日24:00まで。「これから」は今後6時間。「寝る前」は夜の短い番組を探します。
- 普段の好みとは少し違う番組を提示する「発見」
- 作品・ジャンル・人物・放送局・時間帯などを組み合わせた継続的な学習
- 出演者・原作者・脚本家・監督など番組に関わる人物情報を利用したおすすめ
- 同じ作品やシリーズをまとめる番組名の自動整理
- 話数やシリーズ情報を利用した続き物の判定
- 録画傾向の集計・表示
- 録画結果を利用した「取り直し候補」の表示
- 学習データのバックアップ・復元
- おすすめ・学習データ・全蓄積データのリセット

## 使うほど育つおすすめ

AI-rhythmは「何を録画したか」だけを見るのではありません。

たとえば普段なら選ばない作品でも好きな出演者が出ているから見ることがあります。原作者が好きだからドラマを見ることもあります。脚本家や監督をきっかけに新しい作品を見るといった選び方もあります。

AI-rhythmはこうした番組を選ぶ理由につながる情報も学習材料として扱います。

主な学習材料は次のとおりです。

- 作品やシリーズ
- ジャンル
- 番組名に含まれる語句
- 出演者
- 原作者
- 脚本家
- 監督・演出
- 司会・ゲスト・解説などの出演情報
- 制作・音楽などの番組に関わる情報
- 放送局
- 放送される時間帯
- ユーザー自身が行った予約
- 人物を指定して探した操作
- 成功した録画の実績

これらを一つだけで判断するのではなく複数の材料を組み合わせてユーザーごとの傾向を作っていきます。

そのため単純に「ドラマをよく録画するからドラマだけを出す」といった推薦ではありません。

作品そのものを知らなくてもよく見る出演者や関心のある制作陣が関わっていることから候補になる場合があります。反対にタイトルやジャンルが似ているだけで常に強くおすすめするわけでもありません。

利用を続ける中で新しい録画・予約・明示的な操作が増えると学習内容も更新されていきます。

### 自動検索予約も学習材料です

自動検索やキーワード検索は番組表から自分で見つけきれない番組を拾い撮り逃しを防ぐための普段の操作です。AI-rhythmはそこから得られた予約・録画・番組情報も番組表からの直接予約と同じく正の事実として蓄積します。

1番組につきタイトル・ジャンル・出演者や制作陣・放送局・時間帯など取得できた関連項目へそれぞれ1件分の事実を積みます。自動検索・キーワード検索で正の検索条件が実際にマッチした場合その検索条件も別の1件分として積みます。同じ人物が番組情報にも検索条件にも現れた場合は由来の異なる2つの事実として両方を保持します。

NOT / 除外条件は検索対象を狭めるための条件であり好みのマイナス評価には使いません。加点もしません。プログラム予約は番組を選んだ意図を判定できないため予約事実は保持しますが嗜好項目への加点は行いません。

同じ番組の予約と録画成功が両方記録されても同じ予約から生じた出来事を二重加点しません。一方第1話や第2話のように別々の番組として成立した録画はそれぞれ独立した事実として残します。これらの事実は時間経過で減点・消去せず数年にわたる蓄積の中でどの作品・人物・ジャンル・局・時間帯などが継続して増えるかを推薦時に利用します。

### おすすめを表示しただけでは学習しません

おすすめ画面に番組が表示されたことや表示された番組を選ばなかったことだけを理由に好み・嫌いを判断することはありません。

ユーザーの実際の検索・予約・録画など普段の利用で生じた事実を学習材料にします。

## 番組名とシリーズの整理

テレビ番組のタイトルには話数・シーズン・再放送表記・番組枠名・特集名などさまざまな情報が付くことがあります。

AI-rhythmはそれらを単純に削除するのではなく蓄積した番組情報を比較しながらどこまでを同じ作品・シリーズとして扱うべきかを判断します。

十分な判断材料がない場合は無理に統合せず番組情報が増えるまで判断を保留します。

特定の番組名だけを対象にした個別設定を増やすのではなく蓄積された番組データ全体から共通する特徴を学習していきます。

## 「発見」について

AI-rhythmはすでに好きだと分かっている作品だけを並べることを目的としていません。

これまでの録画・予約・人物への関心などから考えて興味を持つ可能性はあるものの普段の選択とは少し異なる番組も候補に加えます。

いつもの番組を見つけやすくしながら自分では検索しなかった番組にも出会えることを目指しています。

## 外部情報について

AI-rhythmの主要機能はTvAIr内に保存された番組表・録画実績・予約実績などのローカル情報だけで利用できます。

番組名や作品情報を確認するために追加情報が有効な場合はTvAIrが管理する外部情報取得機能を補助的に利用することがあります。

現在利用する外部情報サービスはTVmazeです。

AI-rhythm自身が直接インターネットへ接続することはありません。

外部情報の利用は初期状態でOFFです。

外部情報を利用するにはTvAIrの設定で次の条件を満たしている必要があります。

1. TvAIrの「ネットワーク利用」がON
2. AI-rhythmのインターネット利用が許可されている

どちらかの許可がない場合はAI-rhythmは外部情報を利用しません。

外部情報を利用できない場合でも録画実績・予約実績・番組表などのローカル情報を利用したおすすめ・発見・学習などの主要機能はそのまま利用できます。

録画ファイルそのものを外部サービスへ送信することはありません。

## 保存するデータ

AI-rhythmは利用を続けることで学習に使う情報を蓄積します。

主に次の情報を保存します。

- 成功した録画の実績
- ユーザー自身が行った予約や明示的な操作から得た学習情報
- 作品・人物・ジャンルなどに関する学習情報
- 番組名やシリーズを整理するための学習情報
- おすすめや発見に利用する学習情報
- 外部情報から得た補助情報
- 利用回数などの集計情報

録画ファイルそのものをAI-rhythmが保存・管理することはありません。

現在の情報から再計算できるおすすめ順位などは可能な限り固定した結果として保存せず蓄積した情報を現在の判定方法で再評価します。

## バックアップと復元

AI-rhythmの設定画面から蓄積したデータをバックアップできます。

長期間利用した学習データや録画実績を引き継ぎたい場合はPCの再構築やTvAIrの再インストールを行う前にバックアップしてください。

保存したバックアップはAI-rhythmから復元できます。

## リセット

AI-rhythmには用途の異なる3種類のリセットがあります。

### おすすめリセット

おすすめに関するユーザー設定を初期状態へ戻します。

### 学習データリセット

学習した好みや判定情報をリセットします。

蓄積した録画実績は残します。

### 完全リセット

AI-rhythmが蓄積した学習情報や録画実績を含めすべての保存データをリセットします。

## インストール

1. 配布ZIPを任意のフォルダへ展開します。
2. Visual Studio 2022で `AIrhythm.BasicPlugin.sln` を開きます。
3. ソリューション構成を `Release` にします。
4. 使用する環境に合わせて `x64` または `x86` を選択します。
5. ビルドして生成された `AIrhythm.BasicPlugin.dll` を確認します。
6. TvAIrを終了します。
7. `AIrhythm.BasicPlugin.dll` を `TvAIr\Plugins` フォルダへ配置します。
8. TvAIrを起動しAI-rhythmを利用できることを確認します。

公開用ソースでは `Release` ビルド時の開発者向け診断が既定でOFFです。Visual Studio 2022で上記の手順どおりにビルドすると診断を含まないDLLが生成されます。

コマンドラインからビルドする場合も以下の指定で診断をOFFにできます。

```powershell
dotnet build AIrhythm.BasicPlugin.sln -c Release -p:Platform=x64 -p:TvAIrDeveloperDiagnostics=false -warnaserror
dotnet build AIrhythm.BasicPlugin.sln -c Release -p:Platform=x86 -p:TvAIrDeveloperDiagnostics=false -warnaserror
```

## 更新

旧バージョンから更新する場合はTvAIrを終了してから新しい `AIrhythm.BasicPlugin.dll` へ置き換えてください。

長期間蓄積した学習データがある場合は必要に応じて更新前にバックアップしてください。

- **おすすめ精度の改善**：作品名・シリーズ・話数・副題の識別を改善しました。異なる作品の誤統合や作品名の過剰な短縮を抑制しました。
- **自律学習の改善**：番組情報から学習した作品名をおすすめへ反映する際の判定を厳格化しました。

- **外部情報取得の安定性改善**：取得サイズ上限を超過したエピソード情報の繰り返し要求を抑えました。取得できない場合もローカル情報で処理を継続します。
- **保存データの保護**：学習データ・録画実績・取り直し候補の永続保持を維持し関連処理の安定性を改善しました。

- 蓄積した番組情報から番組名の特徴やシリーズのまとまりを継続的に学習し特定の番組ごとの個別ルールを増やさずに判定を改善していく仕組みを強化しました。
- 「見つける」画面のおすすめと発見候補へ学習結果をより広く反映し普段の好みに近い番組と少し意外な番組を組み合わせて提示するようにしました。

- 外部の補助情報を確認する対象は録画・予約などの利用実績に加えて過去の問い合わせが実際に役立ったかも蓄積して選ぶようにしました。限られた問い合わせ回数をより有効な番組確認へ回せるよう継続的に調整します。
- 学習データのバックアップ・復元・各種リセットを整理し長期間蓄積したデータを管理しやすくしました。
- TvAIrのライト／ダークテーマ変更をAI-rhythm画面へすぐ反映できるようにしました。
- おすすめ計算や番組名整理などの処理を大幅に効率化し番組数や学習データが多い環境でのメモリ使用量と処理負荷を改善しました。
