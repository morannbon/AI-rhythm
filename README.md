# AI-rhythm v1.0.4

AI-rhythmは、TvAIrの番組表、録画実績、予約内容などをもとに、
ユーザーの録画傾向に合う番組を見つけやすくするTvAIr Pluginです。

おすすめ番組の表示、録画傾向の確認、番組発見、予約、学習データの管理などを行えます。

---

## 主な機能

- 録画・予約実績をもとにしたおすすめ番組の表示
- 録画傾向の分析表示
- 取り直し候補の表示
- 新番組候補の表示
- リズム検索による番組発見
- おすすめ番組からの予約
- 好みとして扱う言葉、除外したい言葉による調整
- 学習データのリセット
- 蓄積データのバックアップと復元
- 外部の番組・作品情報の補助利用
- TvAIrのライト／ダーク表示への対応

---

## 動作環境

- TvAIr 1.2.1以降
- Windows
- .NET 8
- x64 / x86

AI-rhythm v1.0.4はTvAIr 1.2.1以降で使用してください。

TvAIr 1.2.0は対応対象外です。

---

## インストール方法

### 1. ZIPを展開する

`AI-rhythm_v1.0.4.zip` を任意のフォルダへ展開します。

### 2. Visual Studio 2022で開く

展開したフォルダにある `AIrhythm.BasicPlugin.sln` を
Visual Studio 2022で開きます。

### 3. Releaseビルドする

使用するTvAIrに合わせて、

- Release / x64
- Release / x86

のいずれかを選択してビルドします。

### 4. Pluginを配置する

生成された `AIrhythm.BasicPlugin.dll` を、
TvAIrの `Plugins` フォルダ直下へ配置します。

既に旧バージョンを使用している場合は、
TvAIrを終了してから旧DLLを新しいDLLへ置き換えてください。

### 5. TvAIrを起動する

TvAIrを起動し、Plugin一覧またはメニューから
「AI-rhythm」を開きます。

AI-rhythmの画面が表示されれば導入完了です。

---

## 使用方法

TvAIrからAI-rhythmを開くと、
現在の番組情報と蓄積された録画・予約実績をもとにおすすめ番組を表示します。

番組を選択すると、TvAIrの予約機能を使って予約できます。

設定画面では、

- おすすめの調整
- 学習データ
- 外部情報
- データの保全

を変更できます。

---

## おすすめの調整

設定画面から、

- 好みとして扱う言葉
- おすすめから外したい言葉

を登録できます。

「おすすめリセット」を実行すると、
これらの設定を初期化できます。

---

## 学習データ

録画や予約などから得られた傾向を、おすすめの判断に利用します。

「学習データリセット」を実行すると、
AI-rhythmが学習した好みや傾向を初期化します。

蓄積した録画実績そのものは残ります。

---

## データの保全

AI-rhythmが蓄積したデータは、
今後のおすすめや番組判定に利用されます。

設定画面からバックアップと復元を行えます。

「完全リセット」を実行すると、
録画実績を含むAI-rhythmの蓄積データを初期化します。

通常の設定は保持されます。

---

## 外部の番組・作品情報

AI-rhythm v1.0.4では、
必要に応じてインターネット上の番組・作品情報を補助的に利用できます。

この機能は初期状態ではOFFです。

利用するには、次のすべてが必要です。

1. TvAIr 1.2.1以降を使用していること
2. TvAIrの「ネットワーク利用」がONになっていること
3. TvAIr側でAI-rhythmのインターネット利用が許可されていること
4. AI-rhythm側で「外部の番組・作品情報を利用する」をONにしていること

TvAIrの「ネットワーク利用」がOFFの場合、
AI-rhythmを含むPluginの外部通信は行われません。

外部情報は番組や作品を判断するための補助として利用します。

外部情報を利用できない場合でも、
録画・予約・番組情報を使った通常のおすすめ機能は利用できます。

録画ファイルそのものを外部サービスへ送信することはありません。

---

## 更新方法

旧バージョンから更新する場合は、

1. TvAIrを終了します。
2. 新しいバージョンをReleaseビルドします。
3. `Plugins` フォルダ直下の旧 `AIrhythm.BasicPlugin.dll` を新しいDLLへ置き換えます。
4. TvAIrを起動します。

通常の更新では、これまで蓄積した録画実績や設定をそのまま利用できます。

---

- Visual Studio 2022
- .NET 8 SDK

- Release / x86

を選択してビルドしてください。
