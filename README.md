# AI-rhythm v1.0.5

## v1.0.5 の更新内容

- **おすすめや番組判定の中心を、固定的な条件分岐からAIによる自動学習へ移行しました。** 録画、予約、自動検索、人物、ジャンル、放送局、時間帯などの利用実績を継続的に蓄積し、使うほどユーザーごとの傾向や番組同士の関係を学習します。
- **v1.0.4までに蓄積した録画実績や学習データはv1.0.5へ引き継がれます。** 更新後は、これまで蓄積したデータを新しい自動学習方式で引き続き利用します。
- 番組名やシリーズの判定も、個別番組ごとの固定ルールだけに頼らず、蓄積した番組データから共通する構造を学習する方式へ拡張しました。
- 出演者、原作者、脚本家、監督などの人物情報を継続的に学習し、作品名やジャンルだけでは見つけにくい番組もおすすめへ反映します。
- 外部情報の確認結果も学習し、次回以降の確認対象選びに活用するようにしました。
- 「見つける」画面へ学習結果をより広く反映し、普段の好みに近い番組と新しい発見の両方を提示します。
- 学習データのバックアップ、復元、リセットを整理しました。
- TvAIrのライト／ダークテーマ変更をAI-rhythm画面へすぐ反映できるようにしました。
- おすすめ計算や番組名整理の処理を効率化し、番組数や学習データが多い環境での処理負荷を軽減しました。
- TvAIrの番組情報更新と画面更新が重なった場合の安定性を改善しました。

## 製品説明

AI-rhythmはTvAIr用のおすすめ・発見プラグインです。

録画や予約を重ねるほど、ユーザーがどのような番組を選ぶのかを学んでいきます。

作品やシリーズ、ジャンルだけを見るわけではありません。

出演者、原作者、脚本家、監督などの人物情報も利用します。

放送局や時間帯、これまでの録画、予約、検索条件も判断材料になります。

いつもの好みに近い番組だけを並べることも目的としていません。

これまでの傾向から興味を持ちそうな少し意外な番組も「発見」として提示します。

使い始めた直後は判断材料が多くありません。

録画や予約などの実績が増えるほど、AI-rhythmが利用できる情報も増えていきます。

## 主な機能

- 録画・予約履歴を利用したおすすめ番組の表示
- 普段の好みとは少し違う番組を提示する「発見」
- 作品、ジャンル、人物、放送局、時間帯などを組み合わせた継続的な自動学習
- 出演者、原作者、脚本家、監督などの人物情報を利用したおすすめ

- 学習データのバックアップ・復元
- おすすめ、学習データ、全蓄積データのリセット

## AIによる自動学習

AI-rhythmは、番組ごとの固定条件だけでおすすめを決める方式ではありません。

録画、予約、自動検索、人物情報、ジャンル、放送局、時間帯など、日常利用で増えていく事実を蓄積します。

蓄積した情報は、その後のおすすめや番組判定へ継続的に反映されます。

使い続けることで、ユーザーごとの傾向や番組同士の関係を少しずつ学習していきます。

特定の番組や人物だけを対象にした条件分岐を増やすのではなく、蓄積されたデータ全体から共通する傾向を利用します。

## 使うほど育つおすすめ

AI-rhythmは「何を録画したか」だけを見るわけではありません。

たとえば普段なら選ばない作品でも、好きな出演者が出ていることで見る場合があります。

原作者をきっかけにドラマを見ることもあります。

脚本家や監督から新しい作品を見つけることもあります。

AI-rhythmは、こうした「番組を選ぶ理由」につながる情報も学習材料として扱います。

主な学習材料は次のとおりです。

- 作品やシリーズ
- ジャンル
- 番組名に含まれる語句
- 出演者
- 原作者
- 脚本家
- 監督・演出
- 司会・ゲスト・解説などの出演情報
- 制作・音楽などの番組に関わる情報
- 放送局
- 放送される時間帯
- ユーザー自身が行った予約
- 人物を指定して探した操作
- 成功した録画の実績

一つの材料だけで好みを決めることはありません。

複数の材料を組み合わせて、ユーザーごとの傾向を作っていきます。

そのため「ドラマをよく録画するからドラマだけを出す」といった単純な推薦にはなりません。

作品そのものを知らなくても、よく見る出演者や関心のある制作陣が関わっていることで候補になる場合があります。

逆に、タイトルやジャンルが似ているだけで常に強くおすすめするわけでもありません。

新しい録画や予約、明示的な操作が増えると学習内容も更新されます。

## v1.0.4からのデータ引継ぎ

v1.0.4までに蓄積した録画実績や学習データはv1.0.5でも引き続き利用します。

v1.0.5へ更新しても、学習を最初からやり直す必要はありません。

これまで蓄積したデータを、新しい自動学習方式で再評価しながら利用します。

長期間使って蓄積したデータも、そのまま今後のおすすめや発見へ活用されます。

### 自動検索予約も学習材料です

自動検索やキーワード検索は、番組表から自分で見つけきれない番組を拾うための通常の操作です。

撮り逃しを防ぐためにも利用されます。

AI-rhythmは、そこから得られた予約や録画、番組情報も正の事実として蓄積します。

番組表から直接予約した場合と同じ扱いです。

1番組につき、取得できた項目へ1件分の事実を積みます。

対象にはタイトル、ジャンル、出演者、制作陣、放送局、時間帯などがあります。

自動検索やキーワード検索で正の検索条件が実際にマッチした場合は、その検索条件も別の事実として積みます。

同じ人物が番組情報と検索条件の両方に現れた場合は、由来の異なる2つの事実として保持します。

NOT / 除外条件は検索対象を狭めるための条件です。

好みのマイナス評価には使いません。

加点にも使いません。

プログラム予約は番組を選んだ意図を判断できません。

そのため予約事実は保持しますが、嗜好項目への加点は行いません。

同じ番組の予約と録画成功が別々の場所に存在しても、同一予約IDに属する一連の出来事を二重加点しません。

一方で第1話、第2話のように別の番組として成立した録画は、それぞれ独立した事実として残します。

蓄積した事実は時間経過だけを理由に減点や消去をしません。

数年にわたる蓄積の中で、どの作品や人物、ジャンル、放送局、時間帯が継続して増えているかを推薦時に利用します。

正規表現などのNOT・除外条件も同じです。

検索結果を絞るための条件であり、指定された語句や対象を「嫌い」と判断することはありません。

### おすすめを表示しただけでは学習しません

おすすめ画面に番組が表示されただけでは学習しません。

表示された番組を選ばなかったことだけを理由に、好みや嫌いを判断することもありません。

実際の検索、予約、録画など、普段の利用で生じた事実を学習材料にします。

## 番組名とシリーズの整理

テレビ番組のタイトルには多くの付加情報があります。

話数、シーズン、再放送表記、番組枠名、特集名などです。

AI-rhythmは、それらを単純に削除するわけではありません。

蓄積した番組情報を比較しながら、どこまでを同じ作品やシリーズとして扱うべきか判断します。

十分な判断材料がない場合は無理に統合しません。

番組情報が増えるまで判断を保留します。

特定の番組名だけを対象にした個別設定を増やす方式ではありません。

蓄積された番組データ全体から共通する特徴を学習していきます。

## 「発見」について

AI-rhythmは、すでに好きだと分かっている作品だけを並べることを目的としていません。

これまでの録画や予約、人物への関心などから見て、興味を持つ可能性がある番組も候補に加えます。

その中には普段の選択とは少し違う番組も含まれます。

いつもの番組を見つけやすくしながら、自分では検索しなかった番組にも出会えることを目指しています。

## 外部情報について

AI-rhythmの主要機能はローカル情報だけで利用できます。

利用するのはTvAIr内に保存された番組表、録画実績、予約実績などです。

番組名や作品情報を確認するときに追加情報が有効な場合は、TvAIrが管理する外部情報取得機能を補助的に利用することがあります。

AI-rhythm自身が直接インターネットへ接続することはありません。

外部情報を利用するには、TvAIr側で次の条件を満たす必要があります。

1. TvAIrの「ネットワーク利用」がON
2. AI-rhythmのインターネット利用が許可されている

AI-rhythmのインターネット利用許可は初期状態ではOFFです。

利用する場合はTvAIrのネットワーク設定から許可してください。

どちらか一方でも許可されていない場合、AI-rhythmは外部情報を利用しません。

外部情報を利用できなくても主要機能は利用できます。

録画実績、予約実績、番組表などを使ったおすすめ、発見、学習はそのまま動作します。

録画ファイルそのものを外部サービスへ送信することはありません。

## 保存するデータ

AI-rhythmは利用を続けることで学習用の情報を蓄積します。

主に次の情報を保存します。

- 成功した録画の実績
- ユーザー自身が行った予約や明示的な操作から得た学習情報
- 作品・人物・ジャンルなどに関する学習情報
- 番組名やシリーズを整理するための学習情報
- おすすめや発見に利用する学習情報
- 外部情報から得た補助情報
- 利用回数などの集計情報

録画ファイルそのものをAI-rhythmが保存・管理することはありません。

現在の情報から再計算できるおすすめ順位などは、可能な限り固定した結果として保存しません。

蓄積した情報を現在の判定方法で再評価します。

## バックアップと復元

AI-rhythmの設定画面から蓄積データをバックアップできます。

長期間利用した学習データや録画実績を引き継ぎたい場合は、PCの再構築やTvAIrの再インストール前にバックアップしてください。

保存したバックアップはAI-rhythmから復元できます。

## リセット

AI-rhythmには用途の異なる3種類のリセットがあります。

### おすすめリセット

おすすめに関するユーザー設定を初期状態へ戻します。

### 学習データリセット

学習した好みや判定情報をリセットします。

蓄積した録画実績は残します。

### 完全リセット

AI-rhythmが蓄積した学習情報や録画実績を含め、すべての保存データをリセットします。

## インストール

1. 配布ZIPを任意のフォルダへ展開します。
2. Visual Studio 2022で `AIrhythm.BasicPlugin.sln` を開きます。
3. ソリューション構成を `Release` にします。
4. 使用する環境に合わせて `x64` または `x86` を選択します。
5. ビルドして生成された `AIrhythm.BasicPlugin.dll` を確認します。
6. TvAIrを終了します。
7. `AIrhythm.BasicPlugin.dll` を `TvAIr\Plugins` フォルダへ配置します。
8. TvAIrを起動します。
9. AI-rhythmを利用できることを確認します。

## 更新

旧バージョンから更新する場合はTvAIrを終了してください。

その後、新しい `AIrhythm.BasicPlugin.dll` へ置き換えます。

v1.0.4までの録画実績や学習データは引き継がれます。

長期間蓄積したデータがある場合は、必要に応じて更新前にバックアップしてください。
