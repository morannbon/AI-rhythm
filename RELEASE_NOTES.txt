AI-rhythm v1.0.3
2026-08-29

・録画実績を中心とした分析ダッシュボード
  - 録画総本数
  - ジャンル別内訳
  - タイトル上位10
  - よく録る放送局 上位10
  - 録画時間帯
  - 曜日別録画傾向
  - おすすめ候補の傾向

・おすすめ
  - 成功した録画実績、予約、シリーズ、タイトル傾向、放送局、時間帯、最近の選択をもとに評価
  - ジャンル嗜好は成功した録画実績を正本として評価
  - 有効な自動検索・キーワード由来予約は継続的な嗜好として強めに評価
  - 無効予約は正の嗜好に使わず、無効であることだけを負の嗜好とは判断しない
  - 「納得が先、意外性が後」を優先し、固定比率ではなく説明できる候補密度に応じて発見候補を混ぜる
  - 局・時間帯だけでは納得候補にせず、番組内容側の根拠を必要とする
  - 件数合わせのために弱い推薦を水増ししない
  - 同一シリーズ一致と同じ予約・録画由来のタイトル語を二重加点しない
  - 録画実績が少ないジャンルは、別の強い一致理由がない限り低めに評価
  - 発見候補であることだけを理由に好みスコアを引き上げない
  - 100点は強い継続実績がある場合に限定
  - 表示スコアは候補母集団の平均50・標準偏差10を基準とする相対表示
  - 強いシリーズ証拠は同一の安定系列キーに限定し、部分一致だけでは録画履歴・自動検索予約を継承しない
  - 予約済み状態や番組情報の取得経路は嗜好スコアへ加減点しない

・発見ハブ
  - 今から見られる
  - いま録画中
  - 取り直しチャンス
  - 今夜のピックアップ
  - 好みに刺さる新番組
  - 見逃し再放送レーダー
  - いつもと違う発見
  - 今週の期待作

・取り直しチャンス
  - 録画失敗または録画品質に問題があった番組から再放送候補を探索
  - 取消・中止は対象外
  - 番組の同一性と品質状態を候補順位へ反映

・リズム検索
  - 気分、時間、目的から番組候補を探索
  - 「気になる」の追加・解除はRuntimeの正式Action経路へ統一
  - 入力値を正規化し、不正な制御文字や危険な入力を受け入れない

・学習情報リセット
  - AI-rhythm独自の最近の探し方と「気になる」情報をまとめて初期化
  - TvAIr本体の録画履歴、予約、録画ファイル、通常設定は保持

・UI
  - タイトル部の「更新」を復活し、長時間開いた画面を明示的に再取得可能
  - 更新入口はタイトル部に一本化し、Floating更新ボタンは使用しない
  - ワイド画面3列、中幅2列、狭幅1列の分析レイアウト
  - Runtime UI Theme Contract v2へ追従
  - 通常操作、hover、選択済み、無効、Primary、Secondary、Dangerを本体semantic stateへ統一
  - ライト／ダークテーマへ追従
  - チャート補助文字を本体テーマの共通文字色へ統一
  - 通知音、トースト通知は使用しない

・Runtime / SDK
  - Runtime descriptor、Typed Event、Storage、Action、MediaInsightsの正式契約を使用
  - 録画失敗と録画結果確定イベントを取り直し候補へ反映
  - MediaInsightsのジャンル情報を分析表示へ使用
  - 同梱TvAIrPlugin SDKを1.1.5へ更新（Service Identity Contract / Runtime Hover Contract / Runtime Window Lifecycle Contractを含む）
  - AI-rhythmはpage型のためToolWindow StatePatch APIは使用しない
  - 未使用のPath Picker権限は要求しない

・バージョン
  - 1.0.3
